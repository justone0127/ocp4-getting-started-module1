== 개요

이 워크샵은 개발자의 관점에서 OpenShift를 실습 중심으로 소개합니다. 실제로 손으로 해보는 대화형 실습을 통해, OpenShift 플랫폼에서 컨테이너화된 애플리케이션을 빌드하고 배포하고 관리하는 방법을 배웁니다.

모든 실습은 **Red Hat Developer Sandbox**에서 진행하며, Sandbox가 여러분에게 제공하는 Project(``<사용자명>-dev``) 하나에 애플리케이션을 배포합니다.

== 배우게 될 내용

**OpenShift 접속하기:**

* OpenShift 명령줄 클라이언트와 웹 콘솔 사용하기
* OpenShift 개발자 인터페이스를 살펴보고 핵심 개념 이해하기
* Sandbox Project의 범위와 제약 사항 이해하기

**애플리케이션 배포와 관리:**

* 기존 컨테이너 이미지를 사용하여 애플리케이션 배포하기
* Pod의 구조와 이미지 라이프사이클 이해하기
* 레이블을 사용하여 구성 요소를 식별하고 정리하기

**네트워킹과 접근:**

* Service로 Pod에 대한 안정적인 접근 지점 만들기
* Route를 통해 애플리케이션을 외부 사용자에게 노출하기
* OpenShift Route와 Kubernetes Ingress의 차이 이해하기

**스케일링과 자가 치유:**

* Deployment와 ReplicaSet의 관계 이해하기
* 다양한 트래픽 부하를 처리하도록 애플리케이션 스케일링하기
* Pod가 사라졌을 때 OpenShift가 자동으로 복구하는 과정 확인하기

NOTE: 이 워크샵은 Java 애플리케이션을 사용하지만, 여기서 다루는 개념과 기법은 .NET, Node.js, Python 등 다른 런타임으로 빌드된 애플리케이션에도 동일하게 적용됩니다.

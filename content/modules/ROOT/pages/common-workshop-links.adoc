[#application_urls]
== 애플리케이션 URL

실습 중 만든 Route의 실제 주소는 Sandbox 클러스터마다 다릅니다. 웹 터미널에서 다음 명령으로 확인하세요:

[source,bash,role="copypaste"]
----
oc get routes -o custom-columns=NAME:.metadata.name,URL:.spec.host
----
